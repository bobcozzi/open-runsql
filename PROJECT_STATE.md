## What this is

Desktop "Run SQL Scripts"-style app for IBM i, targeting macOS/Windows/Linux.
Formerly `ibmi-jdbc-bridge-starter` (renamed). Git repo initialized locally
(not yet pushed to GitHub; planned: `gh repo create BobCozzi/open-runsql`).

Architecture: Wails v3.1.0 webview UI → Go service → child-process Java jar
(JTOpen JDBC + CommandCall) → IBM i. The jar is a replaceable headless adapter
(JSON-lines over stdin/stdout); no Java UI.

## Layout

- `java-bridge/` — Main.java bridge; ops: connect/disconnect/executeSQL/
  fetchRows/cancelSQL/executeCL/getCmdXml/commit/rollback/setAutoCommit/
  getConnectionInfo/shutdown. Build: `cd java-bridge && mvn clean package`
  → `target/ibmi-jdbc-bridge.jar`. JT400 21.0.7, extended metadata on, CL msg
  types mapped to *COMP/*DIAG/*INFO/*ESCAPE/... (see clMessageTypeName).
- `wails-app/` — Go module `github.com/BobCozzi/open-runsql/wails-app`.
  - `main.go` — v3 `application.New` + `app.Window.NewWithOptions`.
  - `app.go` — the bound service (Connect/Run/Fetch/CancelSQL/Disconnect/
    GetCmdXml/profiles/Detach/Attach/ListDetached/workspace updaters).
  - `workspace.go` — WorkspaceStore: per-connection state, `workspace:changed:<id>` events.
  - `internal/bridge/client.go` — JSON-lines client for the jar (+ test).
  - `frontend/` — TS + Vite. `src/main.ts` (tabs, panes, run modes, splitter,
    profiles), `src/sqltypes.ts` (cl-prompter type mapping), `src/statements.ts`
    (statement splitter), `src/clprompter/` (parser+model+validate+view ported
    from cozzi-cl-prompter — files copied, NOT shared with that repo).
  - `frontend/bindings/` — generated by `wails3 generate bindings`.
  - `frontend/tests/` — Vitest (41 tests). Run: `npm test`; Go: `go test ./...`.
- `go-stub/`, `ts-client/` — original CLI test harnesses (kept).

## Build/run (macOS)

```sh
cd open-runsql/wails-app
go build -tags production -o ibmi-run-sql . && ./ibmi-run-sql
# or: make build && ./ibmi-run-sql
```

macOS notes: plain `go build -tags production` works on v3.1 (the old
`CGO_LDFLAGS=-framework UniformTypeIdentifiers` workaround was Wails v2-only —
verified unneeded on v3.1.0 on this machine, macOS 27.2 arm64, SDK 13.3).
Wails CLI: `~/go/bin/wails3` v3.1.0. `wails3 dev` = hot reload.

## Conventions / gotchas

- Formatter reindents files on save — when an edit fails to match, re-read the
  file (often 4-space instead of 2-space).
- `npm`/`go build` must run from the right dir (`wails-app/frontend` vs
  `wails-app`); several past failures were cwd-only.
- zsh: no bare `==`/`===`; quote them.
- User prefs: fully free-form RPG (no /FREE), no emojis in commits/PRs/code.
- Tests: `make test` in wails-app runs Vitest + go test.
